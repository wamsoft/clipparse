# clip_doctor (レイヤ単位の除去・修復) の CSP 実機確認

`tools/clip_doctor.py` を新設しました。`.clip` をレイヤ単位で診断して、
壊れたレイヤの**除去**と、マスク・サムネイルなど**部分的な切除**ができます。

自動テストと参照整合性 (`clip_validate`) は全部通っていますが、
**「行ごと消してポインタを 0 にする」操作を CSP が受け付けるか**は
実機でしか分かりません。`samples/doctortest/` に 5 ファイル置きました。

すべて **CSP で作った正常なサンプルに doctor の操作だけを加えたもの**です
(壊れたファイルは入っていません。落ちる可能性は低いはずですが、
万一落ちたらそのファイル名だけ記録してスキップしてください)。

> **結果 (2026-08-24): 全項目 OK — 1 巡で完了**。
> マスク外し・サムネイル行削除とも CSP 5.0.4 が受け付けることが確定。
> 確定事実は [CLIP_FORMAT.md](CLIP_FORMAT.md) §2.3「レイヤ手術」に [実測] で記載した。

---

## 確認してほしいこと

### ① `d1_remove_layer.clip` — レイヤ除去 (opacity.clip から レイヤー 1 を除去)

- [x] 開けるか (落ちないか)
- [x] レイヤ構成が **用紙 + レイヤー 2 の 2 枚だけ**になっているか
- [x] **開いた直後から**絵が正しいか (レイヤー 2 の半透明の絵 + 用紙)
- [x] 上書き保存 → 開き直しで壊れないか

### ② `d2_remove_folder.clip` — フォルダごと除去 (folder.clip から フォルダー 2 を除去)

- [x] 開けるか
- [x] **フォルダー 2 とその中のレイヤー 2 が両方消えて**、
      フォルダー 1 (中にレイヤー 1) と用紙だけになっているか
- [x] 上書き保存 → 開き直しで壊れないか

### ③ `d3_remove_text.clip` — テキストレイヤの除去 (text.clip から「あいうAB1」を除去)

テキストレイヤは FK の無い付随データ (外接矩形ラスタ等) を持つので、
その掃除に取り残しがないかの確認です。

- [x] 開けるか
- [x] 「横書きABCDE」だけが残り、**テキストとして編集できる**か
- [x] 上書き保存 → 開き直しで壊れないか

### ④ `d4_mask_drop.clip` ← **本命 1** — マスクだけ外す (mask.clip の レイヤー 1)

壊れたマスクの修復手段として「マスク一式 (連鎖 + サムネイル) を消して
`LayerLayerMaskMipmap` / `LayerLayerMaskThumbnail` を 0 にする」を実装しました。
**マスク無しの普通のレイヤとして扱ってくれるか**が焦点です。

- [x] 開けるか
- [x] レイヤー 1 が**マスク無し**になっていて、絵は丸ごと残っているか
      (マスクで隠れていた部分が見えるようになっているのが正)
- [x] レイヤーパレットの表示が変でないか (マスクの残骸アイコンなど)
- [x] このレイヤに**新しくマスクを作れる**か
- [x] 上書き保存 → 開き直しで壊れないか

### ⑤ `d5_thumb_drop.clip` ← **本命 2** — サムネイル行ごと削除 (opacity.clip の レイヤー 1)

これまで実機確認済みなのは「実体だけ消す (行は残す)」でした。今回は
壊れたサムネイルの修復手段として **`LayerThumbnail` の行ごと消して
`LayerRenderThumbnail` を 0** にしています。

- [x] 開けるか
- [x] レイヤー 1 の**サムネイルが表示される**か (CSP が作り直すのが期待。
      空白のままでも、上書き保存 → 開き直しで出るなら OK と記録してください)
- [x] 上書き保存 → 開き直しで壊れないか
