# CSP 実機で作成をお願いしたいサンプル一覧

保存先は `samples/`。すべて `.clip` 形式で保存 (`ファイル > 別名で保存` → CLIP STUDIO FORMAT)。

**共通のお願い**

- ファイル名は下の「保存名」のとおりにしてください (ツールの想定名です)。
- キャンバスサイズは小さくて構いません (**400x300 px 程度**)。ファイルが小さいほど
  解析が速く、差分も読みやすくなります。
- 作ったら **CSP のバージョン** (`ヘルプ > バージョン情報`) を
  `samples/versions.txt` にメモしていただけると助かります。
  `Layer` テーブルの列構成がバージョンで変わるためです。
- 「新規作成 → 即保存」と書いてあるものは、**何も描かずに**保存してください。
  中身が空でも `Layer` の列の生え方を見るのが目的です。

## 優先度 A — 形式の未知数を閉じる (これが一番効きます)

現在の 4 ファイルはすべて 8bit カラー (`CanvasChannelBytes = 1`) なので、
`Offscreen.Attribute` の `color_mode` の値 (33 / 17 / 1 を観測) が何を意味するのか
確定できていません。**基本表現色を変えたファイルが 1 つずつあれば確定します。**

新規作成ダイアログの「**基本表現色**」を変えるだけです。

| # | 保存名 | 作り方 | 何が分かるか |
|---|---|---|---|
| A-1 | `gray_empty.clip` | 基本表現色 = **グレー** で新規作成 → 即保存 | グレー文書の `color_mode` / `num_channels` |
| A-2 | `gray_drawn.clip` | 上と同じ設定で、**適当に何か描いてから**保存 | 実画素ありのグレー面。プレーン構成の確定 |
| A-3 | `mono_empty.clip` | 基本表現色 = **モノクロ** で新規作成 → 即保存 | モノクロ文書の `color_mode` |
| A-4 | `mono_drawn.clip` | 上と同じ設定で、**適当に何か描いてから**保存 | 実画素ありのモノクロ面 |

> 補足: 前回「16bit / CMYK」もと書きましたが、CSP のキャンバスにその選択肢は
> 無いはずです。**新規作成ダイアログで実際に選べる基本表現色だけ**で構いません。
> もしお使いのバージョンに他の色深度の選択肢があれば、それも 1 つずつお願いします。

## 優先度 B — テンプレート方式のための「機能別」ファイル

CSP は **その文書で使っている機能に応じて `Layer` の列を作ります**
(`emptyanime.clip` と `emptyimage.clip` の差はちょうど `AnimationFolder` の 1 列)。
つまり「後からその機能を足したいなら、その機能を含むファイルを種にする」必要があります。

いずれも **カラー / 400x300 / 中身は最小限** で構いません。

| # | 保存名 | 作り方 |
|---|---|---|
| B-1 | `text.clip` | テキストレイヤを 1 枚。文字は「あいうAB1」程度 |
| B-2 | `vector.clip` | ベクターレイヤを 1 枚。線を 2〜3 本描く |
| B-3 | `mask.clip` | ラスタレイヤ 1 枚に**レイヤマスク**を付けて、マスクを一部塗る |
| B-4 | `clipping.clip` | ラスタ 2 枚。上のレイヤを「**下のレイヤでクリッピング**」に設定 |
| B-5 | `folder.clip` | 通常フォルダ 1 つとパススルーフォルダ 1 つ。それぞれ中にレイヤ 1 枚 |
| B-6 | `filter.clip` | **色調補正レイヤ** (トーンカーブ) を 1 枚 |

## 優先度 C — 合成の検証用

合成実装の正解合わせに使います。`CanvasPreview` に完成画が入るので、
**1 ファイルで複数モードを一度に検証できる作り**にしたいです。

### C-1 `opacity.clip` — 不透明度だけの検証

```
下地   : 全面を単色で塗ったレイヤ (例: 濃い青)
上に   : 全面を別の単色で塗ったレイヤ (例: 赤)、不透明度 50%
```

まずこれが合わないと先へ進めないので、一番最初に使います。

### C-2 `blendmodes.clip` — 合成モードの一括検証

**同時に重ならないよう、各レイヤは画面の別々の場所だけを塗る**のがポイントです。
そうすると 1 枚のプレビュー画像から全モードを individually 検証できます。

```
下地   : 全面に横方向のカラーグラデーション (明→暗が入っていると差が出やすい)
その上 : 同じ色の小さい矩形を 1 つだけ持つレイヤを複数枚。
         矩形の位置を少しずつずらして重ならないように並べ、
         レイヤごとに違う合成モードを設定する
```

全 27 モードは大変なので、**まずは下記 8 つ**で構いません:

`乗算` / `スクリーン` / `オーバーレイ` / `覆い焼き(発光)` / `加算(発光)` /
`比較(暗)` / `差の絶対値` / `輝度`

レイヤ名をモード名にしておいていただけると、突き合わせが自動化できます
(例: レイヤ名 `乗算`)。

## 優先度 D — 書き込み検証の下準備 (CSP 作業は不要)

こちらで生成したファイルを CSP で開いていただく確認です。**まだ作っていない**ので、
サンプル作成が終わってから改めてお願いします。内容は:

1. 無変更で読み書きした `.clip` が CSP で開くか
2. 不透明度だけ変更した `.clip` が開くか、値が反映されているか
3. **サムネイルを空にしたファイルを CSP が再生成してくれるか**
   → これが通るとレイヤ追加の実装が大幅に楽になります
